WAY OF THE SAMURAI 4 LAUNCHER

QUICK START
1. Install the game from Steam and sign in to the Steam client. Start the game once, then close it.
2. Download Steamless from https://github.com/atom0s/Steamless. Open Steamless,
   select the game's WayOfTheSamurai4.exe, and unpack it. Steamless creates an
   unpacked .exe beside the original. Use Steamless only with a game you own.
   Do not share the unpacked game executable.
3. Extract this ZIP and keep all its files together. Open WOTS4-Launcher.exe.
   Select the game folder if it was not found automatically.
4. Click Enable 60 FPS and select the unpacked .exe when asked. The launcher
   prepares the tested 60 FPS patch and matching stock 30 FPS files. The button
   then switches between 60 FPS and Restore 30 FPS. Close the game first.
5. Choose your graphics settings. Apply Settings saves them; Apply Settings +
   Launch saves them and asks Steam to start the game so Steamworks can initialize.
   Keep the launcher open while playing if the loading-screen warning is enabled.
   Your choices are remembered.

The launcher includes borderless fullscreen, Alt+Tab protection, FOV, texture
filtering, depth of field, bloom, and an optional black-screen loading warning.
Keep the launcher open during play if you want the loading warning. The 60 FPS
patch keeps scripted cutscenes and menus at 30 FPS.
